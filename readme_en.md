# Wine Fox VRChat Avatar Project Files

Wine Fox (character) is from the [Touhou Little Maid](https://modrinth.com/mod/touhou-little-maid) mod of [Minecraft](https://www.minecraft.net/).

Original work: 完美冻结 星屑海螺 哥斯拉（映素团队）白帆小喵 蓝玫瑰 墨染逝羽 Maks怜悯 浅陌菌 祸御神 羊毛 再来几斤小莫莫 Tex\_offcial

Wand of Symmetry, Sweet Roll, Chocolate Berries, Wrench, Paper Stick, Honeyed Apple, Potato Cannon, Builder's Tea, Blaze Cake (items) are from the [Create](https://modrinth.com/mod/create) mod of [Minecraft](https://www.minecraft.net/).

Creative Physics Wand (item) is from the [Create: Aeronautics](https://modrinth.com/mod/create-aeronautics) mod of [Minecraft](https://www.minecraft.net/).

Cake, Poisonous Potato, Golden Carrot, Apple, Chorus Fruit, Sweet Berries (items) are from [Minecraft](https://www.minecraft.net/).

The performance rank of this avatar is Good on Windows, Android, and iOS.

The ears, hair, bow, tail, and skirt of this avatar all have physical or simulated physical effects.

##### Project Files

assets/ -- Contains all the files needed to build this avatar in Unity.

blender/ -- Blender project files and scripts.

脚本与批处理/ -- Python scripts used for batch processing the model, mostly depending on Pillow.

新小莫莫酒狐/ -- Original files of the Wine Fox model, from 再来几斤小莫莫's Afdian [https://afdian.com/a/starmoon679](https://afdian.com/a/starmoon679).

原始资源/ -- Original resource files from Minecraft, Create, and Create: Aeronautics.

中间资源/ -- Intermediate save files transferred from Blockbench.

wine fox.unitypackage -- Exported Unity package for easier importing.

dev.vrlabs.world-constraint-1.2.5.unitypackage -- World constraint, see details at [https://github.com/VRLabs/World-Constraint](https://github.com/VRLabs/World-Constraint).
